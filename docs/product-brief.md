# 产品需求摘要

> 来源：公开分享的飞书《产品需求文档》，最后更新显示为 9 月 14 日。本文件是 2026-09-16 的结构化摘要，不替代源文档。

## 产品定位

“无限连接”是公益行业资源聚合、供需连接与经验沉淀平台，服务公益机构、公益从业者、志愿者、专家及资源提供方。它是信息中介和社区平台，**不是公开募捐平台**。

核心价值可以概括为：

1. 聚合分散在政府网站、基金会、企业和行业渠道中的公开信息；
2. 降低机构寻找资金、物资、场地、人才和专业能力的成本；
3. 让供需双方产生可统计、可回溯的有效连接；
4. 沉淀真实、专业、去煽情的公益实践经验。

## 目标用户与核心任务

| 用户 | 首要任务 |
| --- | --- |
| 公益机构管理者 / 项目人员 | 找资助、物资、场地、人才、工具；发布供需与项目动态 |
| 基金会 / 企业 CSR / 资源方 | 发布资助或资源；找到可信的合作机构与项目 |
| 公益从业者 / 求职者 | 找岗位、培训、行业资料与同行经验 |
| 志愿者 | 找到与时间、地域、技能匹配的服务机会 |
| 专家 / 顾问 | 展示专业能力，与有需求的机构建立联系 |
| 平台运营与审核志愿者 | 审核内容、维护来源与时效、处理举报和风险台账 |

## 完整功能蓝图

源文档提出以下内容板块：

1. **首页**：平台定位、重点资源、AI 问答、意见收集和必要的合规说明；
2. **公益活动**：项目进展、活动动态和机构日常实践；
3. **资金与物资**：资助、政府购买服务、企业 CSR、机构需求和物资供给；
4. **场地供需**：公益活动空间、办公位、培训场地的供给与需求；
5. **人力与专家**：招聘、志愿者、专业志愿者和专家智库；
6. **能力工具**：培训、行业活动、模板、报告、标准和同行经验；
7. **政策资讯**：政策法规、政策解读、合规指南和行业动态；
8. **机构名录**：源文档路线图中规划为后期能力。

平台能力还包括个人 / 机构账号、投稿审核、收藏订阅、评价、贡献积分、个性化信息流、AI 辅助采集和后台管理。

## 内容的共同数据要求

所有资源类内容至少应具备：

- 标题和简要说明；
- 内容类型、领域与适用地域；
- 发布主体及主体类型；
- 原始来源 URL；
- 原文发布日期、平台收录时间和最近核验时间；
- 截止时间或有效期（如适用）；
- 当前状态：待审核、有效、即将截止、已过期、已撤回；
- 商业服务 / 付费内容的显著标注（如适用）。

## 合规底线

以下要求应被视为产品约束，而非页脚文案：

1. 平台不开展公开募捐，不代收、代管捐款或物资；
2. 严禁个人求助、大病筹款、私人收款码和账号信息；
3. 机构间项目申报 / 合作信息必须与面向公众的募捐信息严格区分；
4. 用户联系方式默认隐藏和脱敏，产生明确对接意愿后才按规则开放；
5. 投稿、动态、评论和评价执行先审后发；
6. AI 只做采集与初筛辅助，不能代替人工核验或直接发布；
7. 政策必须标注权威原文，AI 解答必须声明以官方文件为准；
8. 自动采集要遵守来源网站条款、robots 协议和版权边界。

## 原路线图

- **一期（0–3 个月，PC Web）**：资源聚合、供需对接、基础社区与完整风控；
- **二期（验证后 3–6 个月）**：个性化、互动评价、能力工具增强和 AI 助手；
- **三期（6 个月后）**：机构名录、影响力模型、小程序和更完整的数据能力。

这个路线图表达了正确的“先验证再扩展”原则，但一期仍包含较多独立业务模型，建议进一步缩小，见 [`mvp-content-proposal.md`](./mvp-content-proposal.md)。
