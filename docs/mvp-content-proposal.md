# 初版网站内容范围（讨论稿）

## 已确认范围

初版同时开放 7 个栏目：

1. 首页；
2. 公益活动；
3. 资金与物资；
4. 场地供需；
5. 人力与专家；
6. 能力工具；
7. 政策资讯。

七个栏目并行上线，但底层应共用“选源—录入—审核—展示—对接—复核”的内容闭环，而不是开发七套彼此独立的系统。

## 各栏目的初版内容

### 1. 首页

- 一句话定位与全站搜索；
- 七个栏目入口；
- 即将截止资源（7 天 / 30 天）；
- 最新核验的精选内容；
- 平台审核方式与信息可信度说明；
- 内容纠错、举报与推荐来源入口；
- 平台介绍、联系方式与非募捐平台声明。

### 2. 公益活动

- 公益项目进展；
- 公开活动与参与机会；
- 机构的实践记录与经验复盘；
- 按领域、地域与时间筛选；
- 初版以阅读和跳转原文为主，暂不开放评论、评分和复杂社区互动。

### 3. 资金与物资

- 基金会 / 慈善会资助；
- 政府购买服务；
- 企业 CSR 合作；
- 项目实施伙伴招募；
- 机构间物资供给与需求；
- 申报截止日期、状态和原始申请入口。

### 4. 场地供需

- 免费或低价公益活动空间；
- 共享办公位与培训场地；
- 场地需求；
- 按地域、用途、容纳人数、时间和费用筛选；
- 设备与一般物资仍归入“资金与物资”，避免栏目重叠。

### 5. 人力与专家

- 公益行业全职、兼职和实习；
- 普通与专业志愿者机会；
- 专家 / 顾问名录及专业领域；
- 初版岗位跳转原发布方投递，不在站内保存简历；
- 专家信息只做展示与联系意向，不在站内交易。

### 6. 能力工具

- 培训课程、行业沙龙和研讨会；
- 项目管理、财务、传播、筹款等工具模板；
- 行业报告、白皮书、标准和 SOP；
- 同行经验文章；
- 明确标注免费 / 付费、来源和下载条件。

### 7. 政策资讯

- 现行政策法规；
- 政策解读与合规指南；
- 行业动态资讯；
- 强制关联权威原文、发布机构、生效时间和适用地区；
- 已废止政策不进入默认列表，但保留历史检索；
- 平台解读和 AI 摘要均不得表述为权威法律结论。

## 共用内容模型

七个栏目优先使用一套基础字段，并按栏目增加扩展字段：

| 基础字段 | 说明 |
| --- | --- |
| 标题 | 保持事实性，不做夸张改写 |
| 栏目与内容类型 | 决定展示位置和扩展字段 |
| 发布主体 | 原始发布机构或作者 |
| 领域 / 地域标签 | 用于统一搜索和筛选 |
| 发布时间 / 截止时间 | 截止时间可为空，不能猜测 |
| 摘要 | 平台编辑的事实摘要 |
| 来源 URL | 强制字段，指向原文 |
| 最近核验时间 | 平台最后确认来源和状态的时间 |
| 审核状态 | 待审核、已通过、已驳回、待复核 |
| 展示状态 | 有效、即将截止、已过期、已撤回 |
| 商业属性 | 免费、付费或不适用 |

## 共用运营闭环

```text
人工选源 / 用户投稿 → 录入 → 人工审核 → 公开展示
                                      ↓
用户搜索 / 筛选 → 打开原文或提交对接意向 → 记录结果
                                      ↓
                        定期复核、过期下架、处理纠错
```

AI 可以辅助提取字段、查重和标记风险，但不能绕过人工审核直接发布。

## 初版暂不做

- 站内支付、捐款或代收物资；
- 用户发布后自动上线；
- 站内简历、私信和联系方式批量开放；
- 项目 / 机构评分与排行榜；
- 积分与影响力模型；
- 专家预约交易；
- 个性化推荐；
- AI 自动采集后自动发布；
- AI 政策结论或“权威解读”；
- 独立 App / 小程序。

这些能力不是永久取消，而是在七个基础栏目稳定运营后再排期。

## 下一轮需要确认的问题

1. 七个栏目中，首页首屏优先展示哪三个？
2. 每个栏目上线前至少需要多少条真实种子内容？
3. 内容由谁采编、谁复核？每周可投入多少人时？
4. 初版是否开放用户投稿？如果开放，是邀请制还是所有人均可提交后审核？
5. 什么结果算一次“有效连接”：点击原文、提交意向，还是双方确认合作？
6. 首发范围是全国，还是先限定部分地域 / 公益领域？
