# 参考材料观察

## 网页参考稿

压缩包包含两版静态网页：

- **第 1 版**：首页、公益活动、资金与物资、场地、人力与专家、能力工具、政策资讯；
- **第 2 版**：在上述结构上新增机构名录，并增加了详情弹层、登录 / 注册等交互样例。

可沿用的产品思路：

- 按“资源任务”而非组织架构进行导航；
- 资源卡片突出类型、地域、截止时间和原文入口；
- 首页突出即将截止内容；
- 详情中保留来源与申请流程；
- 多处展示合规与责任边界。

不能直接沿用的内容：

- 页面中的项目、机构、统计数字和截止日期多为演示数据，未核验；
- 两版导航和栏目边界并不一致；
- 首页信息量过大，七到八个平级入口不利于初版验证；
- “场地”页面混入设备和物资，与“资金与物资”存在重复；
- 招聘、志愿者和专家实际是三种不同的数据模型与审核风险；
- 政策解读需要明确来源、时效和责任边界，不能使用示例稿直接上线。

因此参考稿应作为信息架构素材，而不是开发验收标准。

## 公益招聘网站信息库

Excel 共 3 个工作表：

1. `公益招聘网站信息库`：标注收录 58 个网站 / 平台；
2. `按岗位类型找渠道`：按全职、社工、CSR / ESG、实习、志愿者、国际 NGO 等任务给出渠道建议；
3. `说明与更新记录`：记录范围、链接状态、风险提示与季度复核建议。

它适合成为“来源目录”，而不是直接成为前台岗位数据。使用时还需要：

- 给每个来源记录抓取 / 转载许可、robots 规则和推荐采集方式；
- 重新核验链接状态和栏目位置；
- 区分“公益行业岗位”与政府补贴性质的“公益性岗位”；
- 任何岗位都回链到原发布方，提醒用户核验机构资质且正规招聘不收费；
- 对来源建立更新频率、重复内容和下架策略。
